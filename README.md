One funny name for a band made of robots, plus a few words on its hit song, written by a small deterministic Python program. The program writes exactly one line to `/output/entry.txt`:

> Fleetwood Mac Address - their hit 'Go Your Own Way (Firmware Update Required)' plays on repeat because nobody can find the drummer to stop it.

## Run it

```sh
python3 main.py
```

Set `ENTRY_OUTPUT_DIR` to choose the output directory. No dependencies, no network, no randomness — the same line every run.
